# 멜야옹 체크기 — 마비노기 버프·디버프 알림

## 실행 / 배포
- **사용자**: GitHub 릴리스(https://github.com/ImaHost/checkbuff/releases)의 `MelyaongChecker.exe` 하나만 받아 실행하면 됩니다.
  - 실행하면 새 버전이 있는지 확인하고, 있으면 오른쪽 위 **업데이트** 버튼이 켜집니다 (누르면 받아서 다시 시작).
  - **패치노트** 버튼으로 버전별 변경 내용을 볼 수 있습니다.
  - 설정·학습 데이터는 각자 PC 의 `%APPDATA%\CheckBuff\` 에 저장되어 업데이트해도 유지됩니다.
    처음 실행하면 버프 이름·숫자 모양·디버프 아이콘 기본값(`assets/defaults`)이 복사됩니다.
- **개발**: `run.bat` 또는 `py -3 main.py` (소스로 실행하면 코드가 바뀔 때 자동으로 다시 시작).
  - `main` 브랜치에 push 하면 GitHub Actions 가 exe 를 빌드해 릴리스 `v1.0.N` 을 만듭니다 (커밋 메시지가 패치노트).
    릴리스가 필요 없는 커밋은 메시지에 `[skip ci]`.
  - 로컬 빌드: `py -m PyInstaller MelyaongChecker.spec` → `dist/MelyaongChecker.exe`

## 사용법
1. 실행기의 **영역 지정** 버튼 → 실행기가 잠깐 내려가고 화면이 멈추면 버프 목록(아이콘 + 이름 + 남은 시간)을 드래그로 선택합니다.
   - 단축키는 기본으로 꺼져 있습니다 (등록한 키는 게임에 전달되지 않아 스킬 키와 겹치면 안 됨). 필요하면 설정의 '영역 지정 키'에서 고르세요.
2. 선택하면 **버프 선택 창**이 뜹니다.
   - 사용 중이 아닌(회색) 버프까지 **이름과 아이콘만** 목록으로 나옵니다. 처음엔 모두 체크 해제 상태입니다.
   - **체크한 버프만** 사용 중일 때 남은 시간을 확인하고, 30초 이하(설정 가능)가 되면 **"버프 갱신" 창**에 나옵니다.
   - 이름이 틀렸으면 그 자리에서 고치세요. 이름 글자 모양과 함께 기억해서, 다음에 캡처할 때도 고친 이름으로 나옵니다.
   - 나중에 다시 고르려면 실행기의 **버프 선택** 버튼. 이름을 붙이지 않은 버프가 사용 중이면 버튼에 "미등록 n"이 표시됩니다.
3. 실행기의 버프 현황에서도 왼쪽 체크로 알림을 켜고 끄거나, 이름을 클릭해 고칠 수 있습니다.
4. **버프 갱신 창**: 체크한 버프가 **30초 이하**(설정 가능)가 되면 작은 카드로 나옵니다.
   - 남은 시간 적은 순으로 정렬, 주황→빨강으로 진해지고 10초 이하면 깜빡입니다.
   - 오른쪽 위 ◂ 단추(또는 설정의 "알림창 이름 접기")로 **이름을 접어 아이콘+시간만** 볼 수 있습니다.
   - 보여줄 버프가 없으면 숨겨집니다. **알림창·영역 위치 조정**에서 창을 드래그해 옮기고, 오른쪽 아래 모서리를 드래그하면 그 창만 크기가 바뀝니다.
5. **자동 투안** (노래 버프: 전장의 서곡·행진곡·비바체·풍년가)
   - 버프 선택 창에서 노래 버프 타일을 선택하면 **♪ 자동 투안** 체크박스가 생깁니다.
   - 실행기의 "자동 투안" 카드에서 투안마다 **소환 키 / 해제 키**를 등록하고 "사용"을 켭니다 (최대 3마리, Ctrl/Alt/Shift 조합 가능).
   - 대상 버프가 **20~25초(설정 가능) 사이 무작위 시점**에 도달하면 소환 키 → (1초) → 해제 키.
   - 이미 **'버프이름 (투안의노래)'** 가 걸려 있으면 그 버프는 투안이 맡고 있으므로 소환하지 않습니다.
   - 소환 뒤 **'투안의 노래'** 가 켜지거나 대상 버프가 갱신되면 성공. 6초 안에 변화가 없으면 실패로 보고 **다음 투안**을 소환합니다.
   - 한 번 쓴 투안은 **재사용 대기(기본 60초)** 동안 쓰지 않습니다. 모두 대기 중이면 풀리는 대로 소환합니다.
   - 기본으로 **마비노기 창이 앞에 있을 때만** 키를 보냅니다. 투안 줄의 ▶ 로 3초 뒤 테스트할 수 있습니다.
   - ※ 게임에 키를 보내는 매크로 기능입니다. 게임 약관상 제재될 수 있으니 본인 판단으로 사용하세요.

6. **디버프 감시** (실행기 오른쪽 '디버프' 탭)
   - 등록된 디버프 10개(아이콘 12개): 어퍼 · 하이드라 · 데마(2) · 잭 · 케라,미르 · 물풍선 · 야옹 · 프라가라흐(2) · 모모 · 이면.
     `assets/debuffs_12.png` 캡처에서 등록했습니다. 이름이 같은 아이콘은 한 디버프로 묶여 그중 하나만 있어도 '있음'.
     다시 등록하려면 `py tools/register_debuffs.py [캡처.png] [이름 ...]` (왼쪽부터 순서대로).
   - 디버프 탭의 **영역 지정**으로 보스의 **디버프 아이콘 줄과 그 아래 체력바까지** 영역을 지정합니다.
   - **체력바가 보일 때(보스를 선택했을 때)만** 확인합니다. 체력바가 없으면 아무것도 알리지 않습니다.
   - 체크한 디버프가 **없거나**, 아이콘 아래 시간이 `5M` 같은 분 단위가 아니라 **30초 이하 숫자**면 **'디버프 갱신' 창**에 표시합니다.
     아이콘 순서는 상관없습니다. 1초 이상 안 보여야 '없음'으로 칩니다(깜빡임 대비).
   - 아래 시간 숫자는 버프 시간과 같은 폰트라, 버프 쪽에서 배운 숫자 모양으로 읽습니다.
   - 디버프마다 설정 (디버프 탭):
     - **모두 있어야**: 아이콘이 여러 개인 디버프는 전부 있어야 '있음' (프라가라흐). 끄면 하나만 있어도 됨 (데마).
     - **없으면 알림 / 있으면 알림**: '있으면 알림'(붕괴)은 아이콘이 생기면 별도의 **'디버프 발생' 창**에 알립니다.
   - 알림창 3개(버프 갱신 · 디버프 갱신 · 붕괴 알림)는 위치가 따로 저장됩니다.
   - 알림음은 **버프 / 디버프 따로** 켜고 끄며 음량(0~100%)도 따로 조절합니다.
     버프 = '띵', 디버프 갱신 = '딩-동', '있으면 알림' 디버프(붕괴) = 이름을 **음성(TTS)으로 한 번** ("붕괴").

## 동작 방식
| 단계 | 내용 |
|---|---|
| 글자 추출 | 순백(흰 글자)·채도 높은 빨강(30초 이하)만 글자로 봄. 그리고 **검은 외곽선이 붙어 있는 픽셀만** 인정해서 반투명 너머의 빨간 배경을 걸러냄 |
| 이름 | 버프 선택 때만 OCR 로 추정하고, 확정한 이름은 **이름 글자 비트맵**과 함께 저장. 감시 중에는 OCR 없이 비트맵으로 버프를 알아봄 |
| 시간 숫자 | 픽셀 폰트라 OCR 이 9↔3을 헷갈림 → 숫자 **모양 자체를 학습**. 카운트다운을 10초 정도 지켜보면 0~9를 스스로 익힘 (상단 "숫자 학습 n/10"). 학습 전에는 OCR 값을 사용 |
| 검증 | 한 번 읽으면 만료 시각을 예측해 두고, 이후 값은 예측과 맞을 때만 반영. 튀는 값은 연속으로 2~3번 같을 때만 인정. 글자 색(빨강 ↔ 30초 이하)도 교차 확인 |
| 가려졌을 때 | 빨간 배경 등으로 시간을 못 읽어도 예측값으로 계속 카운트다운 ("예측 중" 표시) |

## 참고
- 게임은 **창 모드/전체 창 모드**여야 알림창이 게임 위에 보입니다.
- 실행하면 **관리자 권한 요청(UAC)** 창이 뜹니다. 마비노기가 관리자 권한으로 돌아가서, 게임 안에서 단축키를 받으려면 CheckBuff 도 관리자여야 하기 때문입니다. '아니요'를 누르면 일반 권한으로 실행되지만 게임 안에서는 단축키가 안 먹습니다.
- 알림음은 버프마다 한 번만 울리고, 그 버프를 다시 갱신한 뒤 30초 이하로 내려오면 다시 울립니다.
- 이미 실행 중일 때 다시 실행하면 새로 켜지지 않고 기존 창이 앞으로 나옵니다.
- UI 크기나 해상도를 바꿔도 숫자 모양은 알아서 새로 배웁니다 (OCR 과 계속 어긋나면 스스로 다시 학습).
- 설정/학습 데이터: `%APPDATA%\CheckBuff\` (프로그램이 갑자기 꺼지면 같은 폴더의 `error.log` 에 원인이 남습니다)
- 스크린샷으로 인식 시험: `py tools/analyze_image.py 캡처.png`
